# Code Inspection 演示

将本目录复制到自己的可写文件夹，用 VS Code 打开文件夹，并安装提供的 VSIX。

打开 sample.ts，执行“查看保存观测批次”，先把合法数字改为另一个数字并保存建立基线。然后改成字符串 "wrong"，等待 TS2322 出现再保存；恢复为数字并保存查看修复。

“启动 MCP 服务”后可“通过 MCP 查询当前诊断”或“通过 MCP 续读保存批次”。“暂停保存观测”会清空批次、保留当前诊断查询；恢复后第一次保存重新建立基线。

只需 VS Code 内置 TypeScript 服务，无需为此示例安装 npm 依赖。完整说明见仓库 knowledge/ 中的 G6/G7 文档。
