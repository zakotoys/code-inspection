## 以后怎么维护

每次新增或修复一块功能，同步补充：它解决什么问题；必要概念；输入到输出的数据流；关键代码位置和取舍；复现步骤；边界与失败表现；实际验证和未验证事项。改变行为时更新旧说明，不能让知识库继续描述过时的流程。

理论方案、代码已实现、自动测试通过、用户体验通过、实际 Agent 联调通过，是不同状态，分别记录。新文档加入本索引。除非明确要求，不自动提交或推送。
